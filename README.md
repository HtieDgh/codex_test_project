## Используемые аргументы командной строки

- `-m`, `--mode` (обязательный) – Режим работы.
- `-i`, `--input` (обязательный) – путь к входному CSV-файлу.
- `-o`, `--output` (опционально) – путь для сохранения результатов (обязателен для режимов `file` и `full`).
- `-?`, `--help` – вывод справки по доступным режимам.
- `-s`, `--start_date` - (опционально) дата с которой учитывать статистику. В формате `"M/d/yyyy"`.
- `-e`, `--end_date` - (опционально) дата до которой учитывать статистику, не включительно. В формате `"M/d/yyyy"`.
- `-t`, `--top` - (опционально) Ограничение сверху для Топ-<значение> аналитик. По умолчанию <значение> равно 5.

Аргументы могут задаваться со знаком `=` или без, в короткой или длинной форме, например, команды ниже выполняют одно и тоже: 
```
codex --mode=console --input=sales_5000.csv
```
или
```
codex --mode console --input sales_5000.csv
```
или
```
codex -m console -i sales_5000.csv
```
## Описание сервисов аналитики

Все сервисы учитывают дату, переданную в качестве параметра `--start_date` и `--end_date`. Если один или оба параметры не переданы, то берется значение по умолчанию: `DateTime.MinValue` и/или `DateTime.MaxValue` соответственно.

### Сервис `SumAnalyticsService`

Считает общую сумму продаж по категориям, с учетом скидки `discount`. Затем округляет ее до 2 знаков после запятой, как принято в банковских расчетах (стратегия `MidpointRounding.ToEven`, по умолчанию). Расчет можно представить в виде формулы ниже, результат в `decimal`: 

```
sum = Math.Round( Sale.unit_price * Sale.quantity * (1 - Sale.discount), 2 )
```

В параллельном режиме использует `AsParallel()` у промежуточной коллекции и  `ConcurrentDictionary` для потокобезопасной агрегации.

### Сервис `TopAnalyticsService`

Формирует топ (по умолчанию из 5) товаров (категорий) по общему количеству проданных единиц за указанный период. Если проданных единиц у разных категории одинаково, то категории сортируются по имени категории.

В параллельном режиме использует `AsParallel()` у промежуточной коллекции и `ConcurrentDictionary` для потокобезопасной агрегации.

### Сервис `CustomerAnalyticsService`

Топ (по умолчанию из 5) покупателей по рейтингу. Берется рейтинг, который был последним на момент покупки за указанный период. Если рейтинг одинаков, то покупатели сортируются по id.

### Сервис `DeliveryAnalyticsService`

Среднее время доставки за указанный период.

### Сервис `DiscountAnalyticsService`

Средняя скидка, по категории (группировка по месяцу).

### Сервис `MonthAnalyticsService`

Средняя цена за каждый месяц (группировка по месяцу).

## Ограничения на формат csv файла

В файле обязан быть заголовок. Используется `,` в качестве разделителя ячеек и знак кавычки `"` для экранирования разделителя. Кодировка - `UTF-8`. Перенос строки - CRLF `\r\n` или LF `\n`. Даты в формате `"M/d/yyyy"`.

## Вывод программы

Вывод программы формируют конкретные классы реализующие `IWriter`. Каждый сервис аналитики возвращает свой объект класса `Report`. `IWriter` предоставляет _перегруженные_ методы для каждого `Report` сохраняющие его. Когда требуется вывод, необходимо вызвать метод `IWriter.DoWrite()` (или `IWriter.DoWriteAsync()`), который отформатирует и выведет результат работы. Реализованы:

* `ConsoleWriter` - Запись в стандартный поток вывода (stdout) в формате Markdown.
* `JSONWriter` - Создание и запись в файл, в формате JSON файла.
